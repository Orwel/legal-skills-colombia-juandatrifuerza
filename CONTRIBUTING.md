# Cómo contribuir a legal-skills-colombia

Este es un proyecto abierto de la comunidad jurídica colombiana.
Si eres abogado, estudiante de derecho o legaltech y quieres aportar:

## Requisitos para contribuir un skill

1. Fork del repositorio
2. Crear carpeta: `/area/nombre-skill/`
3. Crear `SKILL.md` usando la plantilla en `/templates/SKILL-template.md`
4. El skill debe tener las **7 secciones obligatorias**
5. Fundamentado en legislación colombiana **vigente** con artículos específicos
6. Jurisprudencia **verificable** — corporación + número + año
7. Pull request con descripción del skill y el área que cubre

## Checklist antes de abrir el PR

- [ ] Frontmatter completo con los 8 campos (incluye `updated`, `difficulty`, `output-type`)
- [ ] Description con mínimo 5 palabras clave de activación
- [ ] Sección de información requerida — Claude pregunta antes de actuar
- [ ] Normas con artículos específicos
- [ ] Jurisprudencia verificable
- [ ] Formato de respuesta con ejemplo
- [ ] Advertencias obligatorias separadas
- [ ] Mínimo 4 errores comunes específicos del área

## Áreas prioritarias que faltan

- Derecho ambiental
- Derecho tributario
- Derecho de propiedad intelectual
- Derecho migratorio
- Derecho del consumidor (SIC)
- Derecho de protección de datos (Habeas Data)

## Estándar de calidad

Los skills deben ser probados con al menos 3 casos reales antes de publicar
y, de ser posible, revisados por un abogado del área específica.
